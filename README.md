# Strata Connector

**Public client for the Strata production pipeline.**

[![Version](https://img.shields.io/badge/version-v1.0.0-blue.svg)](https://github.com/KaartikeyKusshwaha/Strata-Connector)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

This repository contains the Blender add-on (UI, chunk paging, bridge), the local MCP connector, and versioned data contracts. It does **not** contain any engine logic.

## Installation

```bash
pip install -e ".[dev]"
pytest
```
